# Mini Game Runtime

Open this folder in WeChat DevTools as a landscape mini game project.

Current main loop:

- Roll on a 288-cell trade-route board spanning nine regions.
- Form partnerships with NPC-run businesses, handle events, gather supplies and fight road battles.
- Enter any of the 27 existing 2.5D maps as a landmark, then return to the same board tile.
- Advance through morning, noon, noon and evening turns before daily inn settlement.

Landmark exploration:

- Hold and drag the left virtual joystick for eight-direction movement.
- Use `交互` near a highlighted location and `队伍` to switch the leader.
- `镇东风波` is now an optional side quest. Returning to the inn consumes one morning or evening action.

The project uses native Canvas and CommonJS. No build step is required.
