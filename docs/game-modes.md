# 游戏模式设计

## 故事模式

故事模式以《武林外传》前 80 回为章节主线。每一回被拆成 3 个子任务，玩家通过选择角色和经营行动推进任务。

当前规则：

- 每回包含 3 个子任务。
- 子任务绑定指定经营行动，例如招呼客人、调解风波、说书揽客、后厨备菜。
- 行动匹配子任务时推进任务进度。
- 子任务完成后发放资源奖励。
- 当前回全部子任务完成后，自动进入下一回。
- 第 80 回完成后触发故事模式通关。

## 自由模式

自由模式用于练习经营循环，不强制推进章节。

当前规则：

- 资源更宽松。
- 没有章节子任务压力。
- 保留行动点、角色体力、打烊结算和资源变化。
- 后续可接入自由探索、随机来客、地图事件和自定义经营目标。

## 后续扩展

- 将每回 3 个自动生成子任务替换为手工剧情任务。
- 为重点章节加入专属任务，例如比武、断案、潜行、教育选择。
- 给任务加入角色限定和场景限定。
- 接入 Unity 3D 场景中的交互点，让任务直接发生在客栈/七侠镇空间里。
