# 客栈与十字街路线修复 v24

## 修复内容

- 十字街返回客栈的落点从客栈出口触发区内移到右侧地面通道。
- 场景切换增加出口重新激活保护：到达新场景后，必须先离开当前出口区域，才能再次触发该出口。
- 白展堂脚底锚点下移到柜台后地面，并继续由柜台前沿遮挡；不绘制家具内部阴影。
- 客栈楼梯改为贴合斜面和底部台阶的碰撞多边形，角色不能直接走上楼梯。
- 右下桌席碰撞压到桌沿底部，保留通往十字街的地面通道。
- 楼梯前景从当前客栈背景重新构建，消除旧裁切范围造成的拼接块。
- 前景资源加载失败时恢复使用背景裁切遮挡，不再静默跳过遮挡层。

## 自动验证

- 客栈与十字街往返不会在落地后自动反跳。
- 主动离开出口区域后，再次进入仍可正常切换。
- 白展堂站位位于柜台后有效遮挡区。
- 楼梯底部不可行走，右侧出口通道保持可达。
