# 同福客栈经营主线 v5

## 日循环

`早上筹备 -> 中午三轮营业 -> 晚间人物剧情与安排 -> 日结存档`

- 早上可以自由修改排班、菜单与价格，并执行两项筹备行动。
- 中午固定三轮：营业事件、短玩法、营业事件。对话和选择不会推进现实计时。
- 晚上先完成当日人物剧情，再选择装修、客房整理或外出，最后打烊。
- 七日结束后按收入、满意、口碑和秩序给出评级，并开放自由经营。

## 状态边界

- `calendar` 是日期、时段和行动次数的唯一来源。
- `dailyPlan` 保存当日菜单、价格、岗位和筹备结果。
- `service` 保存三轮营业、收入、满意度与短玩法进度。
- `episodes` 保存四名首发角色各三段连续剧情。
- `sideQuests` 保存外出任务、地图位置和时段消耗。
- 探索招募 `recruited` 与客栈岗位 `innUnlocked` 分离。

## 首章内容

七日依次为：新账开门、货车误时、满堂催菜、天字号长客、暗访来客、招牌之争、七侠宴。

现有《镇东风波》完整保留为可选支线，提供食材、菜谱和角色招募奖励，不再直接触发经营日结。
