# 战斗战术反馈 v17 运行审核

## 本轮结果

- 单体普攻与单体武学现在会先进入目标选择；存在多个存活敌人时，玩家必须点选目标才会出招。
- 群体攻击、自疗、群疗、护盾、蓄势与防守仍保持一触即发，不增加无意义确认步骤。
- 敌人行动前增加短暂预警：显示施招者、招式名称、锁定角色和预计伤害；重型与快速敌人具备不同的预警文案与攻击节奏。
- 角色徽章和敌方状态条可点击，打开紧凑状态卡查看体力、真气、攻击、速度、护盾、眩晕、削弱、蓄势与护卫。
- 胜利账册新增章节战绩、同行默契和符合条件的稀有战利品；关系和战利品均使用一次性旗标避免重复领取。

## 体验检查

- 目标选择使用敌人脚底朱砂圈、敌方状态条边框和“点选”标识三重提示；撤销操作保留在场景中央短签中。
- 敌方预警不占用轮盘区域，当前锁定对象可在状态卡中看到对应风险。
- 状态卡为短时信息层，不改变战斗场景镜头，不会遮住右下角武学轮盘。
- 账册继续使用图标和短标签，章节战绩、关系变化和稀有物均由运行时 Canvas 绘制，图片资源缺失不影响战斗。

## 后续建议

1. 在微信开发者工具和真机复核目标选择、撤销和状态卡的单手触控距离。
2. 为敌方预警补充更细的类型图标与声音节奏，并为后续敌人数据定义独立招式表。
3. 将章节战绩进一步汇总到季末评级和客栈经营奖励中。
