# 27 张场景运行接入审计 v34

## 接入原则

本轮不是直接替换背景。每张地图均依次完成：尺寸裁切、压缩、前景拆层、碰撞重建、出口配对、出生点校准、NPC 站位和遮挡检查。

## 运行接口

- 几何：`minigame/data/scene-calibration-v34.js`
- 美术登记：`minigame/assets/art/scene-v34.js`
- 构建：`tools/build_scene_runtime_v34.js`
- 自动检查：`tools/validate_scene_v34.js`
- 运行预览：`tools/render_scene_v34_previews.js`

人物只使用脚底椭圆参与碰撞和纵深排序。前景素材与障碍物共享 `obstacleId`，避免出现“画面挡住但能穿过”或“碰撞挡住却没有遮挡”的错位。

## 验收结果

- 27 张地图背景尺寸与世界尺寸一致。
- 27 张地图的出口尺寸、目标地图和返回出生点合法。
- 所有静态遮挡物均有 Alpha 前景资源。
- NPC、热点和出生点均通过可行走与间距检查。
- 四个 v34 场景分包均低于 3.8 MB。
- 全量自动验证与脚本语法检查通过。

## 人工验收重点

- 客栈：白展堂在柜台后，佟湘玉在柜台前地面，楼梯不可直接走入。
- 十字街：人群不阻塞主路线与四个出口。
- 运河关卡：NPC 位于关卡可行走侧，任务目标不会生成在水面。
- 江南码头：角色位于码头地面，返回点不与香料商重叠。
- 雨夜渡口：栈桥边缘、船体和角色脚底保持可读。
