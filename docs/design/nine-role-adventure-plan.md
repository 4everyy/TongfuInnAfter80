# 同福九梦：九人生涯闯关模式计划

## 一、清理原则

当前项目先从“旧章节热点玩法”切换为“九人身份闯关玩法”。清理范围只处理主流程代码，不删除已有美术资产、章节素材和历史设计文档，避免后续需要复用时找不回来。

保留：
- 微信小游戏项目配置
- 已生成的客栈背景图
- 已有六名角色模型图
- 第一回、第二回相关文档和图片素材

清理：
- 自由模式入口
- 旧版少量热点式剧情主流程
- 旧结算跳转逻辑
- 混在主入口里的临时经营沙盘逻辑

## 二、新模式定位

游戏改为“九人生涯闯关”：

> 九个人，九个身份，九种活法。
> 你选谁，同福客栈的江湖，就从谁的眼里展开。

玩家不是单纯经营客栈，而是在每一回开始前选择一个角色视角。不同角色看到的线索、目标、风险和结局不同。

## 三、基础流程

第一阶段只做基础建设：

1. 首页：同福九梦
2. 九人身份选择
3. 角色江湖开端页
4. 预留剧情接入口

后续剧情接入后，完整流程为：

1. 首页进入江湖
2. 选择角色身份
3. 选择章节关卡
4. 进入该角色视角的章节剧情
5. 节点闯关
6. 结算角色路线变化

## 五、后续剧情接入格式

每个角色的章节剧情建议按以下结构写入：

- chapterId：章节编号
- roleId：角色视角
- title：本关标题
- opening：开场动画文案
- goal：本关目标
- nodes：剧情节点数组
- routes：影响的生涯路线
- endings：结算结果

每个节点包含：

- scene：场景图
- actor：主行动角色
- text：剧情文字
- choices：玩家选择
- effects：数值与路线变化
- next：下一节点
