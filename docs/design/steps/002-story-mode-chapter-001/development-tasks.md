# 第一回玩法扩展开发任务拆解

来源设计：`docs/design/steps/002-story-mode-chapter-001/design.md` 的 `Gameplay Expansion Supplement`。

目标：把第一回从线性剧情推进升级为可点击、可选择、可结算、有支线记忆的微信小游戏章节。

## 版本拆分

### P0：可玩闭环版

目标：玩家能在第一回里点击场景热点，选择处理方案，看到人物动作和资源变化，并完成结算。

交付结果：第一回主线三幕可完整玩通；至少 3 个热点、3 个行动选择、1 个结算页。

### P1：支线内容版

目标：加入第一批支线，让第一回有选择差异和额外奖励。

交付结果：茶客支线、厨房支线、小贝学武支线可触发、完成、影响结算。

### P2：长期钩子版

目标：把第一回结果带入后续章节或自由模式。

交付结果：黑店传闻、芙蓉还债账本、老白身份风险、小贝学武记录被保存。

## P0 开发任务

### T001 章节状态模型

范围：第一回运行时数据。

任务内容：

- 增加第一回专属变量：`guestTrust`、`damageLevel`、`furongGuilt`、`xiangyuStress`、`rumorLevel`。
- 增加三幕状态：`act1_misunderstanding`、`act2_accounting`、`act3_work_trial`。
- 增加支线状态容器：未触发、进行中、已完成、已错过。
- 增加结算数据结构：损失控制、客人安抚、角色关系、开张状态。

验收标准：

- 重开第一回时状态能重置。
- 每次行动后状态能被统一更新。
- 章节完成时能生成结算评分所需数据。

### T002 场景热点系统

范围：第一回全屏动画页面。

任务内容：

- 定义热点数据：id、所属幕、屏幕区域、可见条件、点击反馈。
- 首批热点：门口、破桌、柜台账本、后厨门、小贝位置。
- 点击热点后弹出底部交互面板，而不是直接推进剧情。
- 热点需要有轻提示，例如淡光、轻微缩放、短文字标签。

验收标准：

- 320px 宽屏幕可点击，不误触首页按钮和底部剧情面板。
- 热点只在对应剧情阶段出现。
- 点击不同热点能进入不同交互内容。

### T003 主线选择：门口误会

范围：Act 1。

任务内容：

- 在门口热点中加入 3 个方案：白展堂点穴、佟湘玉讲理、小贝插话。
- 每个方案绑定人物走位、动作表现和结果变量。
- 行动后更新第一回日志和背景阶段。

结果规则：

- 白展堂点穴：`order +`、`furongGuilt 小幅 +`、`rumorLevel 不变`。
- 佟湘玉讲理：`guestTrust +`、`xiangyuStress +`、失败分支 `damageLevel +`。
- 小贝插话：`morale +`、`rumorLevel 可能 +`。

验收标准：

- 选择后人物走到目标点并播放动作。
- 选择后 Act 1 主线可推进到 Act 2。
- 每个方案至少有一句不同反馈台词。

### T004 主线选择：损失清单

范围：Act 2。

任务内容：

- 柜台热点打开“清点损失”玩法。
- 玩家点选破桌、裂碗、倒椅等损坏物。
- 点对增加清单进度，点错触发吕秀才吐槽。
- 点齐 3 件即可过关，点齐全部给额外评级。

验收标准：

- 至少 3 个损坏物可点。
- 点过的物件有账单标记或淡化状态。
- 清单完成后 `damageLevel` 降低，Act 2 可继续推进。

### T005 主线选择：杂役试工

范围：Act 3。

任务内容：

- Act 3 中提供郭芙蓉三选一试工：扫地收拾、修桌补椅、端茶赔礼。
- 每个试工绑定不同动作表现和结算标签。
- 完成后郭芙蓉正式加入客栈阵容。

结果规则：

- 扫地收拾：开张状态更高。
- 修桌补椅：损失控制更高。
- 端茶赔礼：客人安抚更高。

验收标准：

- 郭芙蓉从闯祸站位移动到杂役站位。
- 结算页显示她的加入结果和初始标签。
- 第一回完成后不再重复触发试工选择。

### T006 底部交互面板

范围：移动端 UI。

任务内容：

- 替换单一“继续处理”按钮为上下文交互面板。
- 面板内容包括：热点标题、简短描述、2-3 个处理按钮、预期影响小标签。
- 面板保持轻量，不能遮住主要人物脚底和动作。

验收标准：

- 按钮高度不低于 44px。
- 320px 宽屏幕文字不溢出。
- 不同热点能显示不同选项。

### T007 结算页

范围：第一回完成页。

任务内容：

- 增加四项评分：损失控制、客人安抚、角色关系、开张状态。
- 根据四项评分生成总评级：S/A/B/C。
- 显示本回后续影响：郭芙蓉加入、是否留下传言、是否开启还债账本。

验收标准：

- 第一回完成后进入结算，不直接回首页。
- 结算能明确展示玩家选择造成的差异。
- 玩家可从结算页返回首页或进入下一章占位页。

## P1 开发任务

### T101 支线：被吓跑的茶客

范围：Act 1 门口/桌区。

任务内容：

- 触发条件：Act 1 中制止主线前或刚制止后。
- 选项：送热茶、赔笑解释、让白展堂拦门。
- 结果影响：客人信任、名声、银两。
- 可见反馈：客人从门口回座，桌上出现茶碗热气。

验收标准：

- 支线可完成，也可错过。
- 不同处理方式影响不同结算项。
- 完成后结算页显示“茶客留下”。

### T102 支线：厨房烟火气

范围：Act 2 后厨门。

任务内容：

- 触发条件：Act 2 开始后，主线清算完成前。
- 选项：李大嘴回锅热菜、小贝催客人稍等。
- 结果影响：士气、客人信任、当日收入。
- 可见反馈：后厨热气、桌面热菜、李大嘴动作。

验收标准：

- 支线完成后士气增长。
- 错过后结算提示“菜凉了”。
- 支线不会阻塞主线。

### T103 支线：小贝想学武功

范围：Act 3 小贝位置。

任务内容：

- 触发条件：郭芙蓉被留下还债后。
- 选项：先写作业、只准学一招防身、让白展堂盯着。
- 结果影响：小贝心情、白展堂态度、后续学武支线开关。
- 可见反馈：小贝拿木剑，白展堂摇头或郭芙蓉演示一招。

验收标准：

- 至少一条选择能打开后续钩子 `xiaobeiLearnsMove`。
- 支线完成后结算有单独记录。
- 不影响郭芙蓉加入主线。

### T104 支线：真假黑店传言

范围：Act 2 门口。

任务内容：

- 触发条件：Act 1 使用强硬手段或客人信任过低。
- 选项：佟湘玉出面、白展堂打圆场、吕秀才引经据典。
- 结果影响：名声、掌柜压力、老白身份风险。
- 后续钩子：若未解决，保存 `blackInnRumor = true`。

验收标准：

- 支线不是每局必出，需由前置选择触发。
- 解决与未解决在结算中有明显差异。
- 保存后续状态供第二回或自由模式读取。

### T105 支线：掌柜的债务条款

范围：Act 3 柜台账本。

任务内容：

- 触发条件：损失清单完成后。
- 选项：严格还债、宽厚试用、边干边学。
- 结果影响：银两恢复、郭芙蓉好感、长期成长线。
- 后续钩子：生成芙蓉还债账本初始状态。

验收标准：

- 三个条款产生不同加入标签。
- 文案体现佟湘玉的掌柜风格。
- 结算页展示所选条款。

## P2 开发任务

### T201 后续钩子存档

范围：章节结果持久化。

任务内容：

- 保存第一回关键结果：`blackInnRumor`、`furongDebtMode`、`xiaobeiLearnsMove`、`baiIdentityRisk`、`returningGuestQuality`。
- 为后续章节和自由模式提供读取接口。
- 增加调试输出，方便确认结果。

验收标准：

- 完成第一回后重新进入游戏，结果仍可读取。
- 不同选择会保存不同钩子组合。

### T202 芙蓉还债账本

范围：长期角色成长线。

任务内容：

- 根据 Act 3 条款创建还债进度。
- 绑定自由模式任务：修桌、端茶、扫地、赔礼。
- 还债进度影响郭芙蓉后续可用行动或好感。

验收标准：

- 第一回选择能决定账本初始数值。
- 自由模式能显示还债进度占位。

### T203 老白身份风险

范围：角色风险线。

任务内容：

- 使用白展堂强制处理越多，风险越高。
- 风险高时后续章节出现“有人怀疑老白身手”的事件。
- 第一回只保存风险，不强制展开。

验收标准：

- 白展堂点穴和拦门会增加风险。
- 结算页能显示风险提示，但不剧透太多。

### T204 支线回放记录

范围：章节档案。

任务内容：

- 记录玩家完成了哪些支线、选择了哪些方案。
- 后续在章节档案中可回看简短摘要。
- 用于玩家理解为什么评级不同。

验收标准：

- 第一回结算后有 3-5 条摘要。
- 摘要不超过一屏，适合手机阅读。

## 技术模块拆分

### 数据模块

- 章节状态数据。
- 热点数据。
- 行动结果表。
- 支线任务状态。
- 结算评分函数。
- 后续钩子存档。

### 表现模块

- 热点可视化。
- 底部交互面板。
- 人物走位和动作触发。
- 道具状态变化。
- 结算页。

### 内容模块

- 三幕主线文案。
- 支线触发文案。
- 角色反馈台词。
- 结算评级文案。
- 后续钩子摘要。

1. T001 章节状态模型。
2. T002 场景热点系统。
3. T006 底部交互面板。
4. T003 门口误会主线选择。
5. T004 损失清单主线选择。
6. T005 杂役试工主线选择。
7. T007 结算页。
8. T101 茶客支线。

10. T103 小贝学武支线。

## 第一阶段验收标准

P0 完成时，玩家应该能做到：

- 在第一回场景中点击至少 5 个热点。
- 每一幕至少做一次选择，而不是只点继续。
- 看到人物走位、动作和场景变化。
- 完成第一回后看到差异化结算评级。
- 郭芙蓉加入客栈，并带着一个由玩家选择决定的初始标签。

P1 完成时，玩家应该能感到：

- 第一回不是固定流程，同样剧情能打出不同结果。
- 支线不会喧宾夺主，但会影响评价和后续钩子。
- 角色之间有互动，不只是经营数值按钮。

## 开发注意事项

- 第一回仍是新手关，失败只能降低评级，不应该阻断主线。
- 支线触发要轻，不能让玩家必须读长段说明。
- 移动端上每次只露出 2-3 个选择，不要恢复成大列表 UI。
- 所有点击区至少 44px，底部面板不能遮住角色关键动作。
- 资源变化必须配合一句短反馈，避免玩家只看到数字跳动。
