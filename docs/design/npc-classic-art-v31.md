# NPC 原著角色画像 v31

## 目标

- 开发模式的 36 名市井 NPC 使用《武林外传》原著角色名与人物气质。
- 新画像只提取角色身份、性格和叙事功能，不参考演员五官，不复刻电视剧服装或画面。
- 游戏任务 ID、奖励、地图坐标与旧存档保持不变。
- `originalRelease` 模式继续保留《灯下江湖》的原创姓名和旧运行素材。

## 设计规则

- 先用体型、年龄、姿态和职业道具区分人物，再使用服装配色。
- 画像采用 5.5 头身手绘国风动画风，避免所有 NPC 共用同一脸型与站姿。
- 全身运行图统一为 `192 x 256`，脚底锚点为 `(96, 244)`。
- 每名 NPC 同时提供透明全身图和 `256 x 256` 对话头像。
- 危险人物以伪装或稀有来客身份接入，后续需继续改写专属连续事件，不能长期只使用普通跑腿台词。

## 六组角色

1. 市井经营：小米、钱掌柜、钱夫人、赛貂蝉、小翠、杨蕙兰。
2. 捕快与调查：邢捕头、燕小六、祝无双、展红绫、追风、凌腾云。
3. 师长与艺人：朱先生、窦先生、断指轩辕、诸葛孔方、清风、扈十娘。
4. 危险来客：姬无命、姬无病、上官云顿、平谷一点红、公孙乌龙、谢步东。
5. 家族与权威：佟伯达、佟石头、白三娘、郭巨侠、郭蔷薇、慕容嫣。
6. 特殊客人：杜子俊、金镶玉、包大仁、柳星雨、柳月云、岳松涛。
