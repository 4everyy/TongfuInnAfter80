## 兼容规则

- `unlockedMaps` 只表示地图可进入。
- `visitedMaps` 仍记录玩家实际到访地图。
- `requires / unless` 继续控制场景事件是否出现。
- 地图开放不会自动完成章节、招募角色或发放奖励。
