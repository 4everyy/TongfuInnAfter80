# 经营 UI v12 运行视觉审核

审核基于本轮重新渲染的 `844 × 390` Canvas 画面，不使用旧版缓存截图。

## 1. 全场景经营主页

证据：`outputs/screenshots/season2-05-management.png`

- 状态：通过。
- 客栈场景完整占据画面，右侧面板、抽屉、页签和底部账簿入口均已取消。
- 七个经营物件入口与人物入口可以在场景语义中理解，不再依赖管理后台式导航。
- 物件首次使用显示短标签；点击后只保留图标，任务相关入口继续高亮。
- 仍需在微信开发者工具真机触摸中确认人物与相邻物件的命中区不会误触。

## 2. 柜台与后厨

证据：

- `outputs/screenshots/season2-06-management-counter.png`
- `outputs/screenshots/season2-07-management-kitchen.png`

- 状态：通过。
- 柜台页只负责今日目标、营业预测和开关店；后厨页只负责菜品、价格、采购和备菜。

## 可访问性与限制

- 所有可操作区域至少为 44 逻辑像素，顶部资源避开微信胶囊。
- 截图可以验证层级、字号和对比度，但不能证明真机触摸准确性与动画帧率。
- 最终验收仍需在微信开发者工具中完成物件点击、页面返回、开店、午市、日结和旧存档恢复。
