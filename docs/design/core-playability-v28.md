# 核心可玩性重做 v28

## 目标

先把前三个游戏日做成完整闭环，再扩展到现有章节与地图：

`早晨筹备 -> 三轮营业 -> 人物交流/外出 -> 日结 -> 跨日后果`

## 三日垂直切片

### 第一天：新账开门

- 玩家选择菜单、价格、岗位和两项筹备行动。
- 午市处理“少记的一碗面”、核账短玩法和“咳嗽的老客”。
- 客人的口味、预算、菜品库存和提前备菜共同影响满意度。
- 晚间完成掌柜人物事件并结算第一日。

### 第二天：货车误时

- 供货延迟会真实扣减蔬菜和荤食库存。
- 玩家可缩减菜单、临时补货或接受《迟到的驿信》委托。
- 完成外出委托后，供货路线恢复并写入经营成长记录。

### 第三天：满堂催菜

- 前两日口碑带来额外客流。
- 菜单、备菜、跑堂与后厨岗位共同决定高峰表现。
- 完成三日后记录经营里程碑，并保留客人记忆与菜品熟练度。

## 可玩性联动

- 六道菜拥有成本、售价和口味标签。
- 八类客人拥有偏好、耐心和预算。
- 二十个以上营业事件绑定柜台、灶台、桌席、客房、大门、货架、告示板或后院。
- 菜品售价超过客人预算会降低满意度；公道价格和口味命中会提高满意度。
- 提前备菜会改善每轮出菜，缺货会降低秩序与满意度。
- 连续良好出菜提升菜品熟练度。
- 客人的处理结果会写入跨日记忆，不再是一次性对话。
- 探索任务奖励会登记为经营后果，且不可重复领取。

## 验证

`node tools/validate_core_loop_v28.js`

自动玩家会完整运行三天，检查三轮营业、微玩法、日结、防重复奖励、负库存、跨日后果、存档恢复和场景物件路由。
