# NPC 站位与姿态规范 v35

## 目标

让 NPC 服务场景叙事，同时保留清楚的主通行带、出口和任务物件。站位优先贴合墙面、柜台、货架、摊位、码头货物与河岸等真实工作区域，不把人物平均铺在道路中央。

## 运行规则

- 环境 NPC、支线 NPC 与商贩优先布置在地图左右边缘区域。
- 剧情 NPC 保留在事件发生地附近，但不得阻挡出生点、出口或主通道。
- 常驻 NPC 按前、中、后景深交错布置，同一地图不得有三人共用一条静态脚底线。
- 中央区域最多保留两名具有明确工作台或当前剧情职责的 NPC。
- 左半场 NPC 默认朝右，右半场 NPC 默认朝左，使人物视线回到场景内部。
- 商贩使用工作姿态，守卫使用警戒姿态，普通路人使用放松姿态。
- 具有正式角色图集的 NPC 可播放轻量交互待机；普通 NPC 保持稳定站姿，避免统一上下浮动。
- NPC 移位时，其专属对话与危机热点同步到脚底坐标，不能遗留在旧位置。
- 角色不参与实体堵路；任务距离和视觉站位仍需保持可达。
- 普通姓名牌只在玩家靠近后显示，任务角色例外，避免远处标签再次形成视觉横排。
- 静态 NPC 的上下浮动降到最低；正式角色图集继续使用自身待机或交互动作。

## 特殊场景校准

- 客栈与十字街：中心动线保持空旷，商贩靠柜台或店铺前沿。
- 商会货栈：工头、杂货商靠右侧货箱，环境脚夫靠左侧货区。
- 运河关卡：人物位于闸口可行走一侧，不占用过关路线。
- 江南码头：搬运工、船娘与香料商分布在货物及栈桥边缘，避开四个返回出生点。
- 江南河市：摊贩沿左右市场边缘布置，中央调查路线保持畅通。
- 雨夜渡口：人物沿栈桥边缘分散，脚底不落入水面。
