# 武侠派对棋盘 UI v1

## 设计目标

借鉴多人派对棋盘游戏的高对比、低文字密度、强反馈和竞争信息常驻方式，转换为原创武侠客栈视觉。界面不复制其他游戏的组件、图标或版式。

## 棋盘行动页

- 顶部常驻四名玩家的头像、江湖令、银两和当前行动状态。
- 当前行动者使用金色描边与放大头像，其他玩家保持各自的识别色。
- 左下只显示三格随身锦囊，默认以图标识别道具。
- 右下使用大型漆木骰子按钮，江湖令独立显示在旁边。
- 棋格与路线直接嵌入山河场景，不使用大面积侧栏或账本面板。

## 道具攻击页

- 攻击者与目标分列左右，中间显示道具轨迹、名称和命中反馈。
- 底部只保留效果说明和一个主要执行按钮。
- 目标锁定、免疫、反弹和失效均使用头像边框与图标状态表达。

## 小游戏结算页

- 四名角色按照名次形成高低错落的舞台布局。
- 第一名获得金色光束、头名印与江湖令奖励；其余名次保持角色识别色。
- 奖励数字逐项弹入，归账按钮在奖励演出完成后出现。

## 视觉系统

- 材质：漆木、铜边、玉石、朱砂印、布旗。
- 主色：墨黑、赭金、青玉、朱砂；背景保持鲜亮青绿山水。
- 动效：按压 80ms、回弹 160ms、排名交换 320ms、道具飞行 420–650ms、江湖令演出约 900ms。
- 所有触控命中区域不小于 44 逻辑像素，并避开微信胶囊与底部安全区。
