# NPC 群像与支线扩充 v26

## 入口修复

- 将客栈“常住脚商”从柜台下方窄通道移到左侧候客区。
- 将开场“门口闹事者”移出出口触发区，并设为不阻断移动的事件角色。
- 新增客栈主出生点至十字街出口的带 NPC 寻路检查；闹事者出现时路线仍必须可达。
- 十字街的市井、支线与环境 NPC 改为非阻断角色，保留互动和遮挡，但不再用脚底碰撞封住狭窄通道。
- 新增十字街到客栈、告示巷、纸坊、粮市和货栈五条路线的带 NPC 寻路检查。

## 新增人物

新增 36 名原创 NPC，分为四组：

- 市井居民：药师、戏班女伶、铜匠、面贩、脚夫、说书人、裁缝、伞匠和驿信少年。
- 商旅行会：盐商、粮检、船娘、票手、校秤匠、香料经纪、货栈把头、抄手和商队老掌事。
- 驿路劳作：石匠、樵娘、艄公、纤夫、纸坊学徒、更夫、老巡检、车匠和渔夫。
- 江湖异客：游医、签师、出走学徒、执契人、流民父亲、采茶女、帮厨、锁匠和地图贩子。

所有人物拥有独立脸型、年龄、体型、姿态、服装结构和职业道具，不使用演员肖像或电视剧服装。

## 玩法结构

- 13 条跨地图连续委托：接取、前往目标地图、调查或取回物件、返还并领取奖励。
- 17 条本地场景事件：修理、采集、辨料、机关排序和环境调查。
- 6 条交易与世界传闻：银两交换、经营补给、商路信息及历史背景。
- 新增 128 个交互节点和 98 段 NPC 对话；全项目对话总量达到 159 段。
- 使用 `collect / investigate / repair / mechanism / recipeSample` 五种任务行为，不再统一为一次闲谈或同一种调查。
- 主线、营业与战斗热点优先级高于 NPC 支线，NPC 不会抢占章节交互。
