# 前 11 章美术表现 v19 运行评审

## 评审结论

- 重要对话已从普通矩形弹窗升级为场景内双角色话本，人物、环境和关键物件仍保持可见。
- 普通交互、标准对话和关键剧情使用三档表现，避免所有交互都打断自由移动。
- 五名角色的 15 项技能已具备不同的颜色、母题、节奏和第三技能切入，缺少图片图集时仍有专属 Canvas 演出。
- 地图出口已使用门框、方向墨推和商路图三类过场；切换中冻结输入并在过场中点更换地图。
- 雨夜场景增加雨幕、冷色空气层和薄雾，加载失败时留在安全场景并允许返回。

## 运行截图检查

### 对话

- 双侧人物不会遮挡正文和三个分支按钮。
- 当前说话者亮度明确，听者降低至约 65%，角色关系一眼可读。
- 重要剧情面板占画面高度约 36%，仍能看到客栈空间和任务热点。
- 当前头像素材带纸色底纹，作为开发版角色卡风格可用；正式透明半身像仍需逐人替换。

### 技能

- 佟湘玉使用灯火、账册与算盘轨迹，和白展堂的青玉风痕、穴位光点有明显区分。
- 第三技能切入不会覆盖行动角色状态和底部战斗日志。
- 敌人闪白缩短至 130ms；普通伤害数字为 480ms，暴击接口预留 650ms。
- 技能操作在演出阶段隐藏，业务层伤害与回合顺序保持不变。

### 场景衔接

- 客栈到后院使用 420ms 门框遮罩，户外相邻地图使用 320ms 方向墨推。
- 长途路线预留 700ms 商路图过场；切换期间不会重复触发出口。
- 非出口传送会清理旧返回路线，避免资源失败时误退到无关地图。
