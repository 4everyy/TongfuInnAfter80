# NPC 商业玩法 v30

## 已接入商户

- 马嫂（十字街）：马嫂杂货摊。出售药品、主食、茶饮和荤食补给。
- 温裁缝（告示巷）：温记首饰铺。出售四件可装备首饰。
- 韩铜匠（客栈后院）：韩家兵器行。出售四件可装备兵器。

三名 NPC 原有委托保持不变。对话中可选择接取委托、查看货物或离开；完成委托后仍可继续开店。

## 玩法规则

- 共 12 件商品，随第 1、2、3、5、6、8 章逐步进货。
- 补给品拥有每日限购，购买后直接进入当前分店库存或药品背包。
- 武器和首饰购买后自动装备给当前试装角色。
- 同一件装备只能由一名角色使用，可以在商铺内转交给其他已招募角色。
- 装备属性会进入回合制战斗，影响气血、真气、攻击与行动速度。
- 旧存档自动补齐 `commerce` 与角色 `equipment` 字段，不重置银两、剧情或队伍。

## 运行界面

- 预览目录：`outputs/product-design/commerce-v30/`
- 商品使用图标货架，展示章节锁定、价格、每日限购、持有与装备状态。
- 店铺打开期间暂停自由移动；关闭后回到原场景与原位置。
