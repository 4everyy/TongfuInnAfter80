# 九域商路 288 格棋盘 v1

## 定位

现有客栈 RPG 已切换为大富翁式商路经营玩法。玩家以佟湘玉为固定棋盘主角，通过掷骰、选择岔路、合作产业、结识来客、处理随机风波和进入地标场景，逐步扩大长风客栈的影响力。

原有自由探索没有删除。27 张 2.5D 地图全部作为棋盘地标保留，进入后仍可移动、交互、对话和战斗，离开时回到原棋格。

## 棋盘规模

- 9 个商区，每区 32 格，共 288 格。
- 世界尺寸：`5100 × 3100` 逻辑像素。
- 27 个场景地标，每个现有地图恰好登记一次。
- 72 处合作产业，每名现有 NPC 对应一处独立产业。
- 其余棋格包含 NPC 会面、随机事件、食材补给、护路战、驿马和休息点。

九区分别为：

1. 长风客栈与镇心
2. 老槐巷与东关
3. 镇外桥驿商道
4. 纸墨与转运工坊
5. 商会粮仓区
6. 义仓票契水路
7. 秤契与商盟旧案
8. 江南水巷商区
9. 雨渡与百味香路

## 当前闭环

`掷骰 → 分步移动 → 岔路选择 → 棋格事件 → 经营或场景行动 → 日时段推进 → 每日产业结算`

- 每日四回合：早上、中午、中午、晚上。
- 产业采用合作与升级，不使用现代地产买卖叙事。
- 对手商队会移动、合作产业并支付或收取往来费用。
- 玩家产业每天结算收入，口碑也会形成经营加成。
- 序章目标为：合作 3 处产业、结识 3 名来客、调查 2 个地标并坚持至第 3 日。

## 角色解锁

- 白展堂：完成首次地标调查。
- 郭芙蓉：赢得首次护路战。
- 吕秀才：结识至少 3 名 NPC。
- 李大嘴：抵达江南商区地标。

佟湘玉始终为棋盘主角，解锁角色可进入队伍和战斗编成。

- 战斗中退出后恢复为可重新迎战或绕行的棋格事件，避免存档卡死。

## v2 视觉精修

- 移除调试感明显的矩形区域框与统一菱形格。
- 棋盘改为宣纸舆图：九区使用墨彩地块、山形、水纹、树木、屋脊和区域题签。
- 道路采用深墨路基与赭金路面双层绘制，岔路使用朱砂虚线提示。
- 地标、产业、来客、事件、补给、战斗、驿马和歇脚使用独立手绘节点图形。
- 当前棋格使用低幅金色呼吸环，产业等级和归属使用小型印记表达。
- 骰子使用漆木骰盅和立体骨骰，包含蓄势、翻滚、落定、揭晓四段演出。
- 翻滚持续约 `1320ms`，落定揭晓约 `300ms`，总计约 `1620ms` 后棋子才开始移动。

## v3 武侠山河背景

- 棋盘底层更换为原创青绿山水武侠全景，包含山门、关隘、石桥、河谷、集镇、渡船和驿旗。
- 背景只承载世界氛围，不烘焙文字、棋格、角色或交互状态；288 格路线继续由 Canvas 动态绘制。
- 镜头移动时背景进行轻微横纵视差，九个区域改用低透明矿物色晕染，避免色块覆盖山河细节。
- 主路采用深墨外缘、赭金石板路面和细碎路纹；分岔路线使用朱砂驿道提示。
- 背景加载失败时继续使用程序化宣纸山水后备，不影响掷骰、移动和事件处理。
- 运行图使用 `1688 × 780` JPEG，源图归档在 D 盘，不进入小游戏包。

## v4 鎏金棋格与驿道

- 八类棋格统一采用“鎏金铜器 + 青玉嵌件 + 朱砂漆层”，但分别使用牌楼、铺面、侠客、密卷、宝箱、双兵、驿马和茶盏作为主体轮廓。
- 普通棋格运行显示约 `43px`，地标棋格约 `56px`；实际触控区域仍独立保持不小于 `44px`。
- 棋格源图保留在 `D:\AI\design-assets\grand-board\v4`，运行时只加载 `512 × 256` 的透明 PNG 图集。
- 图集针对手机小尺寸单独提升暗部与金属高光，避免直接缩小概念图后细节糊成黑块。
- 主路改为深墨阴影、旧铜包边、赭金路心和细金刻线四层结构；岔路保留朱砂虚线，保证路线层级清晰。
- 当前落点继续使用低幅金光呼吸；产业归属改用青玉、靛青和朱砂丝旗，产业等级使用小型火漆印记。
- 图集未加载或加载失败时自动回退到原 Canvas 线描图标，掷骰、移动和事件逻辑不受影响。

## v5 地形化商路连接

- 九个区域从矩形边框路线调整为不规则椭圆商路，全部 288 个棋格 ID、事件、产业归属和存档映射保持不变。
- 棋子沿与道路完全一致的二次曲线移动，避免“道路弯曲但棋子走直线”。
- 城镇采用旧铜镶边驿道，山地采用灰绿石道，纸墨区采用墨石路，江南采用青玉木栈水路。
- 跨区域连接使用朱砂桥道和横向桥板纹，东西关口、南北驿道仍连接原有索引位置。
- 当前区域向背景叠加低透明矿物色温，并在路线中心增加局部宣纸雾与边缘压暗，让棋盘融入山河而不是浮在背景上。
