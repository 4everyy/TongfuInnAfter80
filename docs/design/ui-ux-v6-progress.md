## 已落地内容

- `theme.js`：AA 配色、系统字体、间距、圆角、阴影与动效参数。
- `layout.js`：读取安全区和胶囊位置，计算顶部 HUD 右侧避让。
- `canvas.js`：所有通用按钮增加 `2px` 木牌下沉、硬边阴影与按压态。
- `app.js`：相同操作增加 `220ms` 防重复触发。
- 管理和探索 HUD：资源栏自动避开微信胶囊。
- `canvas.js`：监听银两、食材、口碑和秩序差值，以 `420ms` 弧线动画飞向 HUD；动画只读状态，不参与业务结算。
- `canvas.js`：早晨、午间和晚上使用 `500ms` 平滑插值切换光照，经营与探索共用同一时段表现。
- `management.js`：账本内容使用 `180ms` 位移淡入；动画期间拦截内容点击，页签仍可正常切换。
- `inn.js`：装修先显示花费、目标等级和效果，确认前不扣款；取消不会改变资源或行动次数。
- `inn.js`：菜单、定价、排班和筹备操作保存最近一步快照；撤销可恢复资源、客栈状态和行动次数，开门后自动失效。

## 中断后恢复入口

1. 阅读本文件和 `docs/design/management-v5.md`。
2. 检查 `minigame/src/render/theme.js`、`layout.js`、`canvas.js`、`app.js`。
3. 运行 `node tools/validate_ui_v6.js`、`node tools/validate_management_v5.js`、`node tools/simulate_chapter_v4.js`、`node tools/validate_world_v4.js`。
4. 运行 `node tools/render_management_v5.js`，检查 `outputs/wechat-devtools/management-v5/`。
