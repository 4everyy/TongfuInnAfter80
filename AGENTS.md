# Workspace Storage Rule

- Do not install tools, download models, or create dependency caches on drive C.
- Use `D:\AI` for AI tools, models, virtual environments, caches, downloads,
  temporary generation files, and generated source art.
- Use `D:\TongfuInnAfter80` only for game source and optimized runtime assets.
- Before any dependency installation or large download, explicitly set its
  cache and temporary directories to drive D and verify free space there.
- Do not move or delete pre-existing software on drive C unless the user
  explicitly identifies it as disposable.
