# 灯下江湖

原创横屏微信小游戏，使用原生 Canvas、CommonJS 和微信本地存储。

当前主循环：

`柳掌灯自由探索 -> 调查客栈与商路事件 -> 完成营业 -> 结识临时伙伴 -> 推进招募与章节`

微信开发者工具只导入：

`D:\TongfuInnAfter80\minigame`

## 当前实现

- 固定原创主角柳掌灯，新档单人开始。
- 九名原创角色和“相遇—协作—信任—任务—招募—结局”阶段接口。
- 四季、三十二章、二百二十四日的数据框架。
- 96个经营事件、48个探索事件、24个稀有连续事件的数据池。
- 七张可探索地图、八向移动、二维碰撞、跟随、对话和回合制战斗。
- 菜单、岗位、客房、装修、三轮营业和日结。
- v9存档；v3-v8资源与经营进度迁移，旧剧情写入只读档案。

## 关键模块

- `minigame/data/campaign.js`：原创角色、四季章节、日程、招募和事件池。
- `minigame/data/content.js`：当前可运行地图、对话和战斗。
- `minigame/src/core/campaign.js`：人物阶段、临时协作和正式招募。
- `minigame/src/core/store.js`：v9状态与旧存档迁移。
- `minigame/src/inn`、`world`、`combat`：经营、探索和战斗系统。
